GCP 검색 API 비교

Gemini 답변의 근거를 어디서 가져올 것인가 — 공개 웹(Grounding with Google Search)이냐, 내 데이터(Vertex AI Search)냐.

기준일 2026-10-26 · Google Cloud 공식 문서 기준 · 요금은 변경될 수 있으므로 도입 전 공식 가격 페이지를 다시 확인하세요.

명칭 변경 안내 — Vertex AI 플랫폼은 2026-04 리브랜딩으로 Gemini Enterprise Agent Platform이 되었고, Vertex AI Search는 Agent Search로 이름이 바뀌는 중입니다. API 필드명(vertexAiSearch)과 문서 URL에는 기존 이름이 남아 있어 이 문서에서는 익숙한 이름을 그대로 씁니다.

한눈에 보기

공개 웹

Grounding with Google Search

Gemini가 Google 검색을 직접 돌려서 최신 웹 정보로 답변

  • 사전 준비 없음 — 도구 하나만 켜면 끝
  • 검색어 생성 · 검색 · 답변 합성을 Google 서버가 한 번에 처리
  • 뉴스, 날씨, 시세처럼 "지금"이 중요한 질문에 적합
내 데이터

Vertex AI Search (Agent Search)

내 문서·웹사이트를 색인한 검색 엔진을 만들고, 그걸 근거로 답변

  • 데이터 스토어 생성 · 색인이 먼저 필요
  • 독립 검색 제품(검색 API · 답변 API)이면서 Gemini의 근거 소스로도 연결 가능
  • 사내 문서, 제품 매뉴얼, 고객센터 FAQ 같은 RAG에 적합

동작 흐름

Grounding with Google Search
사용자 질문→ Gemini가 검색 필요 여부 판단→ Google 검색 쿼리 생성 · 실행→ 검색 결과로 답변 합성→ 답변 + 출처 메타데이터
Vertex AI Search로 Grounding
① 데이터 스토어 생성 · 문서 색인 (사전 작업)→ 사용자 질문→ 내 데이터 스토어에서 검색→ 검색 결과로 답변 합성→ 답변 + 출처 메타데이터

두 방식 모두 검색이 모델 호출 안에서 끝나는 "서버 측 도구"입니다. LangChain @tool처럼 내 코드가 검색을 실행하지 않습니다.

상세 비교

Grounding with Google Search Vertex AI Search (Agent Search)
근거 데이터 Google 검색 색인 (공개 웹 전체) 내가 등록한 데이터 — 웹사이트(URL 패턴 지정), Cloud Storage 문서(PDF · HTML · TXT 등), 구조화 데이터
제품 성격 Gemini 모델의 기능 (도구 옵션) 독립 검색 엔진 제품. 단독 검색 API로도 쓰고, Gemini 근거 소스로도 연결
사전 준비 없음 데이터 스토어 생성 → 데이터 가져오기(동기화 주기 설정) → 색인 완료 대기. 파싱 · 청킹 옵션 조정 가능
요청 설정 tools: [{ googleSearch: {} }]
도메인 제외, 사용자 위치(latLng) 지정 가능		 tools: [{ retrieval: { vertexAiSearch: { datastore } } }]
데이터 스토어 최대 10개
최신성 Google 검색 색인 수준의 실시간성 마지막 동기화 시점까지 (동기화 주기에 의존)
응답 메타데이터 webSearchQueries, searchEntryPoint(검색 추천 HTML), groundingChunks(출처 URL · 제목), groundingSupports(문장 ↔ 출처 매핑) groundingChunks(내 문서 출처), groundingSupports, retrievalMetadata
요금 구조
  • Gemini 토큰 요금
  • + 검색 쿼리당 요금 — Gemini 3.x: 월 5,000건 무료(3.x 모델 공유), 이후 $14 / 1,000 쿼리
  • Gemini 3부터 프롬프트가 아닌 생성된 검색 쿼리 수로 과금 (한 질문에 쿼리 여러 개 가능)
  • 검색 결과로 들어가는 입력 토큰은 과금 안 함
  • Gemini 토큰 요금
  • + 근거 생성 요금 $2.50 / 1,000 요청 (내 데이터 기반 grounded generation)
  • + 검색 엔진 요금 — Standard $1.50 / Enterprise $4.00 (1,000 쿼리당), 월 10,000 쿼리 무료
  • + 색인 저장 $5.00 / GiB · 월 (10 GiB 무료)
  • 고정 용량 구독형(configurable pricing)도 선택 가능
제한 하루 100만 쿼리 (초과 시 지원팀 문의) 요청당 데이터 스토어 최대 10개
표시 의무 있음 — searchEntryPoint의 검색 추천을 원본 그대로, 답변과 같은 폭으로, 답변이 보이는 동안 항상 표시. 클릭 시 검색 결과로 바로 이동 없음 (내 데이터이므로 표시 방식 자유)
도구 조합 두 검색 도구는 한 요청에서 함께 쓸 수 있음 (웹 + 사내 문서 동시 근거). 단, 검색 도구는 일반 함수 호출 도구와는 한 요청에 섞을 수 없음.
대표 사례 최신 뉴스 요약, 날씨 · 시세, 일반 사실 확인, 범용 어시스턴트 사내 지식 검색, 제품 매뉴얼 Q&A, 고객 지원 챗봇, 정책 · 규정 안내

코드로 보면

Grounding with Google Search · LangChain (web_chat.py 현재 코드)
llm = ChatGoogleGenerativeAI(
    model="gemini-3.8-flash",
    vertexai=True,
    project=project_id,
    location="global",
)
# 내장 검색 도구 연결 — 이게 전부
llm = llm.bind_tools([{"google_search": {}}])
Vertex AI Search로 Grounding · google-genai SDK (공식 문서 예제)
DATASTORE = (
    "projects/PROJECT_ID/locations/global/"
    "collections/default_collection/"
    "dataStores/DATASTORE_ID"
)
tool = Tool(retrieval=Retrieval(
    vertex_ai_search=VertexAISearch(datastore=DATASTORE)
))
client.models.generate_content(
    model="gemini-3.8-flash",
    contents=question,
    config=GenerateContentConfig(tools=[tool]),
)

무엇을 고를까

"오늘", "최신", "지금" 같은 실시간 공개 정보가 필요하다Google Search
답이 사내 문서 · 내 웹사이트 · 제품 매뉴얼 안에 있다Vertex AI Search
공개 웹에 없는 비공개 데이터를 다뤄야 한다Vertex AI Search
준비 작업 없이 오늘 바로 붙여야 한다Google Search
답변 출처를 우리 도메인 문서로만 한정해 환각 위험을 줄이고 싶다Vertex AI Search
사내 규정 + 최신 외부 동향을 같이 근거로 삼아야 한다둘 다 (한 요청에 조합)

이 프로젝트(web_chat.py)에 대입하면

  • 현재: 검색 방식 "Vertex AI Grounding"이 Grounding with Google Search입니다. 모델이 gemini-3.8-flash이므로 월 5,000 쿼리 이후 $14 / 1,000 쿼리가 붙는데, 화면의 예상 비용은 토큰 요금만 계산하고 있습니다.
  • 표시 의무 미충족: searchEntryPoint 검색 추천을 아직 렌더링하지 않습니다. 개인 실습을 넘어 공개한다면 먼저 추가해야 합니다.
  • Vertex AI Search를 추가하려면: 데이터 스토어를 만든 뒤 검색 방식 옵션에 retrieval.vertexAiSearch 도구를 하나 더 붙이면 됩니다. 이 경우에도 CSE 같은 LangChain 함수 도구와는 같은 요청에 섞을 수 없다는 점에 주의하세요.
